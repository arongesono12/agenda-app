Flujo funcional para usuarios

Vista de alto nivel de cómo interactúan los usuarios con autenticación, organismo activo, roles, tareas oficiales, asignaciones múltiples, historial, alertas y checklist personal.

Agenda App
Regla clave: en tareas con múltiples responsables, completar una parte actualiza únicamente la asignación del usuario. La tarea global solo pasa a Completado cuando todas las asignaciones activas están completadas.

Flujo técnico para desarrolladores

Vista de arquitectura: App Router de Next.js, proveedores globales, componentes UI, rutas API, control de acceso, Supabase, correo, Stripe y migraciones.

Next.js + Supabase
La mayor parte de la lógica de negocio está en /api/tareas y /api/historial. El alcance de lectura/escritura se calcula con el rol activo, el organismo seleccionado y las asignaciones del usuario.
